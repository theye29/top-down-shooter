# Untitled Zombie Shooter

My first game made in Godot.

## About

A top down shooter game developed to learn Godot.

## Systems

- Player movement
- Shooting system
- Reloading
- Enemy variations
- Waves system
- Shop and upgrades
- Dynamic music
- Sound effects
