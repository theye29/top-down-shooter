# Untitled Zombie Shooter

Meu primeiro jogo feito em Godot.

## Sobre

Um jogo de tiro top-down desenvolvido para aprender Godot.

## Sistemas

- Movimento do jogador
- Sistema de tiro
- Recarga
- Inimigos com variantes
- Sistema de waves
- Loja e upgrades
- Música dinâmica
- Efeitos sonoros
